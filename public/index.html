Splitwise Personal API Token

Your API Key is used to authenticate requests to Splitwise. It is stored locally in your browser's localStorage and never shared or sent to any server other than our local proxy backend.

How to get your API Key:

  1. Log in to the Splitwise Developer Portal .
  2. Click on "Register your application".
  3. Fill in the fields (you can use dummy URLs like http://localhost:3000).
  4. Click "Register", then under your app details click "Create a personal API key".
  5. Copy the long string provided and paste it above.

Enter Splitwise API Key

Quick Steps:

  1. Go to Splitwise Apps.
  2. Register a dummy app and click "Create a personal API key".
  3. Paste the key here.
