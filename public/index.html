Splitwise optional

This ledger works on its own. If you have existing history in Splitwise you can import it here (read-only, safe to repeat). Splitwise's API now needs a Pro subscription on the developer account, so if this fails nothing else is affected.

The key is kept only in this browser (or in SPLITWISE_API_KEY on the server) and is sent only to this server. Only entries in the household currency whose shares add up are imported; re-importing updates changed entries.

Your data

Everything lives in the server's data/ folder (ledger.json plus a receipts/ folder). Back that folder up and you have backed up everything.
